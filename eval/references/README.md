# Referencias de escaneos

Transcripción de dos páginas por escaneo, con la forma que debería tener una buena conversión:
sin cabeceras ni números de página corridos, sin números de línea ni anotaciones manuscritas,
con los guiones de fin de línea unidos y los párrafos completos. Las llamadas a nota se omiten.
El texto cortado por el borde del escaneo se transcribe tal como se ve.

- `s7-rimas-becquer-1925`: transcripción validada de Wikisource (páginas 20 y 21).
- El resto: borradores preparados a partir de la capa de texto del PDF y corregidos mirando la
  imagen. **Pendientes de revisión editorial.**
